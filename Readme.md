# DigitSketch-AI

**Draw a digit (0-9) on a canvas and watch the model predict it in real time.**

DigitSketch-AI is a handwritten digit recognizer. A Convolutional Neural Network (CNN) is trained on the [MNIST](https://yann.lecun.com/exdb/mnist/) dataset using TensorFlow/Keras, and a [Gradio](https://www.gradio.app/) web app lets you draw a number with your mouse or finger and instantly see the predicted digit with its confidence. The repo also includes an inspection tool that opens up the trained model so you can see its layers, weights, and sample predictions.

## File-by-file guide

| Path | Role | Created by | Used by |
|------|------|-----------|---------|
| `train.py` | Loads MNIST, trains the CNN, evaluates it, saves the model and plots | You (run once) | - |
| `main.py` | Launches the Gradio app, preprocesses the drawing, runs the prediction | You (run any time) | - |
| `inspect_model.py` | Opens the saved model and writes a full inspection report | You (optional) | - |
| `mnist_cnn.keras` | The trained model (architecture and weights) | `train.py` | `main.py`, `inspect_model.py` |
| `training_curves.png` | Training vs. validation accuracy and loss per epoch | `train.py` | Documentation |
| `sample_predictions.png` | Predicted vs. true labels for sample test images | `train.py` | Documentation |
| `model_inspection/` | Folder of generated inspection results | `inspect_model.py` | Documentation |
| `pyproject.toml` | Declares Python version and dependencies | - | `uv`, `pip` |
| `uv.lock` | Exact dependency versions for reproducible installs | `uv` | `uv sync` |

### `train.py` (training)

- Downloads MNIST automatically through Keras (60,000 training and 10,000 test images, 28x28 grayscale).
- Scales pixel values to the 0-1 range and builds the CNN.
- Trains the model, prints the test accuracy, and saves it to `mnist_cnn.keras` in the project root.
- Saves `training_curves.png` and `sample_predictions.png` in the project root.

### `main.py` (the app)

- Loads `mnist_cnn.keras` from the project root. It does not train anything.
- Shows a drawing canvas, preprocesses the drawing, and displays the predicted digit.
- If `mnist_cnn.keras` is missing, it tells you to run `train.py` first.

### `inspect_model.py` (model inspection)

- Reads `mnist_cnn.keras` and writes everything it finds into the `model_inspection/` folder.
- Use it to understand what is inside the trained model without opening any code.

## Model inspection outputs

Everything below is generated by `inspect_model.py` and saved in `model_inspection/`.

| File / folder | What it shows |
|---------------|---------------|
| `model_summary.txt` | Each layer of the model with its output shape and parameter count |
| `architecture.json` | The full architecture configuration of the model in JSON form |
| `sample_predictions.png` | Ten handwritten digits compared with the model's predictions and confidence scores |
| `weight_distribution.png` | A histogram of the values in the first layer's weight tensor |
| `weight_statistics.csv` | Weight statistics per layer, easy to open in Excel or any spreadsheet viewer |
| `predictions.csv` | The model's predictions, also viewable in a spreadsheet |
| `archive_contents/` | The files packaged inside the `.keras` archive (a `.keras` file is a zip, and this folder shows what is inside it) |

Note that `model_inspection/sample_predictions.png` is separate from the `sample_predictions.png` in the project root, which is created by `train.py`.

## Installation

Requirements: **Python 3.11 or newer**.

Clone the repository:

```bash
git clone https://github.com/SureRanganath/DigitSketch-AI.git
cd DigitSketch-AI
```

### Option A: uv (recommended, uses `pyproject.toml` and `uv.lock`)

```bash
uv sync
```

### Option B: pip

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install gradio tensorflow numpy pillow matplotlib
```

## Usage

### Step 1: Train the model (optional if `mnist_cnn.keras` is present)

```bash
# uv
uv run python train.py

# pip / venv
python train.py
```

This takes a minute or two on a CPU and creates (or overwrites) `mnist_cnn.keras`, `training_curves.png`, and `sample_predictions.png`.

> A trained `mnist_cnn.keras` is already included in the repo, so you can skip straight to Step 2. Retrain if you change the model or want to regenerate the plots.

### Step 2: Launch the app

```bash
# uv
uv run python main.py

# pip / venv
python main.py
```

Open the local URL shown in the terminal (usually **http://127.0.0.1:7860**).

### Step 3: Draw and predict

1. Draw a single digit (0-9) on the canvas.
2. The predicted digit appears with its confidence, for example "Predicted digit: **7** (98.2% confident)".
3. The top 3 guesses are listed below with their probabilities.
4. The "What the model sees" panel shows the exact processed 28x28 image used for the prediction.
5. Click **Clear** to erase the canvas and try another digit.

If the model's confidence is below 50%, the app shows "Not sure" with its best guess instead of presenting a weak prediction as certain. You can change this with `CONFIDENCE_THRESHOLD` in `main.py`.

**Tips for best results**
- Draw one digit at a time, large and roughly centered.
- Use a clear, continuous stroke (avoid very thin or faint lines).
- If a prediction looks wrong, check "What the model sees" to see whether the digit was cropped or distorted.

### Step 4 (optional): Inspect the model

```bash
# uv
uv run python inspect_model.py

# pip / venv
python inspect_model.py
```

Then open the `model_inspection/` folder to browse the summary, architecture, weight plots, and CSV files described [above](#model-inspection-outputs).

## How it works

### 1. Model (CNN)

| Layer | Details |
|-------|---------|
| Input | 28x28x1 grayscale image |
| Data augmentation | Random translation, zoom, small rotation (training only) |
| Conv2D + MaxPooling | 32 filters, 3x3, ReLU |
| Conv2D + MaxPooling | 64 filters, 3x3, ReLU |
| Flatten + Dropout | Dropout rate 0.3 |
| Dense | 128 units, ReLU |
| Output | 10 units, softmax (digits 0-9) |

Trained with the Adam optimizer and sparse categorical cross-entropy. For the exact layer shapes and parameter counts of the saved model, see `model_inspection/model_summary.txt`.

### 2. Preprocessing (in `main.py`)

Hand-drawn digits must match the MNIST format, or accuracy drops sharply. Before each prediction the app:

1. Extracts the strokes as **grayscale, white digit on a black background** (inverting automatically if needed)
2. **Crops** to the digit's bounding box
3. **Resizes** the digit to fit a 20x20 box, keeping its aspect ratio
4. Places it in a **28x28** frame and **centers it by its center of mass**
5. **Normalizes** pixel values to 0-1

The constants `IMG_SIZE` (28) and `DIGIT_BOX` (20) at the top of `main.py` control the target size.

### 3. Prediction

The processed image goes into the CNN. The softmax output gives a probability for each digit 0-9, and the highest one is shown as the prediction.

## Troubleshooting

**`AttributeError: partially initialized module 'gradio' has no attribute 'Blocks'`**
A file in your project is named `gradio.py`, which shadows the real library. Rename it and delete the `__pycache__` folder. Never name a script after a library you import (`gradio.py`, `tensorflow.py`, `numpy.py`, and so on).

**`FileNotFoundError: 'mnist_cnn.keras' not found`**
Run `python train.py` first, and run all scripts from the project root.

**Predictions are wrong or "Not sure"**
Draw the digit larger and more clearly, and check the "What the model sees" preview.

**TensorFlow GPU warning on Windows**
Native Windows TensorFlow runs on the CPU. This is expected and fine for this project.

**oneDNN / CPU instruction messages**
These are informational TensorFlow logs, not errors.
